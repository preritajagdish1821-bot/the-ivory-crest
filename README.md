# 🏨 The Ivory Crest — Hotel Room Booking Website

A hotel room booking website built as a practical web-development project. It brings together room information, guest bookings, reviews, and an admin dashboard.

🌐 **Live Website:** [Visit The Ivory Crest](https://the-ivory-crest.onrender.com)

## ✨ Features

* Browse hotel rooms, details, amenities, and photos.
* Submit bookings and view booking confirmations.
* View bookings in the My Bookings section.
* Submit guest reviews.
* Admin login and dashboard.
* Admin can confirm bookings and delete reviews.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* SQLite
* Git and GitHub
* Render

## 🚀 Project Goals

This project helped me practise building a website with a frontend, backend, database operations, and an administrative interface, as well as deploying a project online.
